A hand-motion dataset can test compositional generalisation only when its labels describe the scored motion

To test whether a motion model can recombine what it learned, one holds out a combination of labels. On hand-motion data that removes the motion only if each label describes the motion being scored.

Mu-Hua Wang · National Yang Ming Chiao Tung University

[Paper (PDF)] [All projects]

Not posted to any preprint server. The hosted PDF is the anonymised build, so it carries no author block.

The idea in 20 seconds

A common test of compositional generalisation holds out a combination of labels — an action with a tool, say — while keeping each label in training, then scores the model on the held-out combination. The split is made on labels. In public hand-motion datasets a label often names one thing about a recording that contains more, so a label can be correct and still describe only part of what is scored.

The result: correct labels that describe only half remove the penalty

  • When the label described both halves, the penalty was +17.0 % of the naive error. When it described only the first half, it fell to +3.9 %, not distinguishable from the control.
  • The windows the label did describe lost 82 % of their penalty above the control. So the change was in what the training sets contained, not in what was scored.

A test on new data

Before its data were opened, it was written down that TACO, whose labels each name one tool-use action, would show a penalty above the control. It did: +10.6 % over 40 seeds, and 14.0 points above its own permuted grid. Single seeds ranged from −3.8 % to +27.4 %, so one split is not enough to read the result.

How it was checked

  • A known zero. A synthetic dataset in which held-out pairs are predictable by construction returned +2.6 %. Every penalty is read against this control, not against zero.
  • A shuffled grid. With the label grid permuted, the penalty fell to +3.7 % on OakInk-Image and +1.4 % on GRAB.
  • A planted effect. An interaction planted on GRAB’s real poses was recovered (+13.15 %).
  • Written down first. The settings and readings of the main experiments were written down before training; every sweep run, including those not in the main text, is listed in the paper.

Scope: one prior architecture; the error is reconstruction, not generation; the label condition was changed on one dataset and tested on one other.
