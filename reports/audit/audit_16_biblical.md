# Audit: Section 16 (Biblical-theological reflection) and 16_biblical_refs.md

Auditor: independent fact-check, 2026-11-05. Target files not edited.

Method:
- NRSV 1989 wording was fetched verse by verse from the oremus Bible Browser (`https://bible.oremus.org/?passage=…&version=nrsv`, which states "NRSV © 1989").
- Hebrew comes from the Sefaria API (`https://www.sefaria.org/api/v3/texts/<ref>`).
- Greek NT comes from Biblehub interlinear (`https://biblehub.com/text/<book>/<c-v>.htm`). LXX comes from Brenton via Biblehub (`https://biblehub.com/sep/…`) and from ellopos.net (Rahlfs text).
- Bibliographic records come from the Crossref API, the Open Library search API and web search of library catalogues.
- The ITC documents and the PCT 1990 apology were read in full on vatican.va and pct.org.tw.

Status key:
- **OK**: verified.
- **MINOR**: wording or precision problem.
- **ERROR**: factually wrong.
- **UNVERIFIED**: could not be confirmed from accessible sources.
