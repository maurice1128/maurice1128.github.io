=== HOW BIG IS THE PERTURBATION A NOMINAL CAPTURE ERROR ACTUALLY INDUCES? ===
induced SD : spread produced by the error model alone, over independent realisations
signal SD  : spread across the 66 conditions with no error added
ratio      : induced / signal. Above 1 the error dominates that feature.

  all eighteen S:: features are minima, maxima or ranges - none is a mean over the
  waveform - so per-sample noise is not averaged away in the kinematic tier.
