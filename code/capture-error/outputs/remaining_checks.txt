=== A. IS THE UNIMPAIRED SIMULATED GAIT HUMAN? ===
Measured on the UNIMPAIRED base model - the healthy solution every weakened condition was
warm-started from - over the steady-state window. An earlier version measured the mildest
weakened condition instead, which is not the same object and gave a slower speed.

                   measure   simulated       normative   verdict
               speed (m/s)        1.07        1.2-1.45   BELOW
       cadence (steps/min)       93.75         100-125   BELOW
         stride length (m)        1.37         1.3-1.6   within band
             hip ROM (deg)       64.24           40-50   ABOVE
   knee peak flexion (deg)       58.34           54-64   within band
           ankle ROM (deg)       20.50           22-29   BELOW

  Sources for the bands are listed in the supplement. A value outside a band is not
  automatically a defect - a planar reflex walker is not a person - but it must be
  reported, because every downstream claim assumes this gait is a reasonable stand-in.

=== B. FEATURE COUNT AND CLASSIFIER SETTINGS ===
  L1  camera (sagittal + timing)          33 features
  L2  camera + FORCE PLATE                51 features
      - kinematics only (no timing)       27 features
      - force plate alone                 18 features

  before the objective-term exclusion: S 18, A 9, C 9, G 21  (total 57)
  excluded by rule: 6

  classifier: ExtraTreesClassifier, 100 trees, class_weight="balanced", all other
              scikit-learn defaults (no max_depth, no min_samples_leaf tuning)
  wrapper   : MultiOutputClassifier, one binary tree ensemble per muscle group, ranked by
              predicted probability
  imputation: median, fitted on training folds only
  NO hyperparameter tuning was performed, so there is no inner selection loop and no
  opportunity for selection bias through tuning; the cost is that the settings are not
  optimal for any tier and the comparison between tiers is like-for-like.
  training set size per fold: 66 conditions x 4 noise replicates,
  minus one held-out body.
