# PREREG — 跨關節規則的單肌肉直接檢定 (r421)

**Registered:** 2026-08-26,在 §4 所列任何 cell 存在於磁碟之前。

## 1. 這份註冊為什麼存在

整個專案的機制線一直卡在同一件事:**單一肌肉痙攣的 cell 走不動**,所以「腓腸肌跨膝所以帶著訊號」
從來沒有辦法直接測。

- `MECHANISM_RESULT_r407.json`:重新最佳化,GAS-only 在 KV 0.050/0.070/0.090/0.110 全部 **0/6**;
  SOL-only 在 0.050 只有 3/6(自標 uninformative)。**兩邊都低於本語料庫自訂的 4-cell 門檻,
  所以 r407 從來沒有做出過一個可比的對照** —— 見 `HYP2_BOOKKEEPING_r417.json`。
- `FROZEN_MECHANISM_r410.json`:凍結控制器,全部有病灶的臂 **0/6**,3–5 秒跌倒。已由
  `CORRECTION_r416` / `SELF_CORRECTION_r417` 整份退役。
- `RECON_LOWDOSE_r420.json`(探索性偵察):把劑量降到 0.005–0.040,凍結下**仍然**沒有任何劑量
  讓兩隻手臂同時達到 4/6。**凍結路線關閉。**

**未被嘗試過的是:單肌肉 + 低劑量 + 暖啟動串接。** 串接在本語料庫已被證明會翻轉存活門檻
(`CHAIN_RESULT_r393.json`:KV 0.070 從 0/6 變 6/6),而 r407 用的是未串接的直接注入。

⚠ `RECON_LOWDOSE_r420.json` 是探索性的。它挑選劑量,**它的任何數字都不得作為本註冊的證據**,
包含其中「GAS 比 SOL 更早跌倒」的觀察 —— 該觀察在 §5 中被寫成一個必須在**重新最佳化的新 cell**
上重新檢定的預測。

## 2. 要檢定的主張

> **腓腸肌跨越膝與踝,比目魚肌只跨踝。因此單獨的腓腸肌痙攣會位移膝關節,單獨的比目魚肌痙攣不會;
> 而兩者都會同向位移踝關節。膝的可分性來自跨越關係,不是來自「痙攣」這個標籤。**

`SPANNING_MAP_r403.json` 已從模型檔客觀導出跨越關係;本註冊檢定的是它的**因果後果**。

## 3. 定義,在此固定

語料庫慣例不變:SETTLE 1.00 s、T1 9.73 s、週期完整落在窗口內、丟掉最後一個保留週期、
至少 5 個、stance = `leg0_l.grf_norm_y > 0.05`。Gate G 不放寬。

- **`KNEE_ic`** = `knee_angle_l` 於左腳跟著地,逐週期平均,度。**主要終點。**
- **`ANKLE_st`** = `ankle_angle_l` 於站立期樣本平均,度。**同向對照。**
- **`HIP_ic`** = `hip_flexion_l` 於左腳跟著地,逐週期平均,度。**空對照。**
- **`t_end`** = 模擬結束時間。每個 cell 都要報。

## 4. 確認材料 —— 尚不存在

三個臂,各 6 個 seed(101–106),暖啟動串接,每一階從前一階的最佳 `.par` 續跑:

| 臂 | 痙攣目標 | 階梯 |
|---|---|---|
| **GASONLY** | 只有 `gastroc` | 0.0125 → 0.025 → 0.050 |
| **SOLONLY** | 只有 `soleus` | 0.0125 → 0.025 → 0.050 |
| **BOTH** | `soleus` + `gastroc` | 0.0125 → 0.025 → 0.050 |

共 **54 個最佳化 cell**。全部在本註冊雜湊之後建立。`delay = 0.020`、`allow_neg_V = 0` 不變。
種子控制器為各 seed 的 `R151C` 最佳解,與 r410/r418 相同。

## 5. 註冊的預測

判讀劑量為**兩隻單肌肉手臂都達到 ≥ 4/6 Gate G 的最高階**。若沒有任何一階同時滿足,
本註冊回報 **UNINFORMATIVE**,且不得改用較低門檻補救。

**P1 — 膝,主要預測。** 在判讀劑量,`GASONLY` 的 `KNEE_ic` 相對 `SOLONLY` **更屈**(更負),
且兩臂的 cell 範圍**不重疊**。

**P2 — 踝,同向對照。** 在判讀劑量,`GASONLY` 與 `SOLONLY` 的 `ANKLE_st` **重疊**。
若踝也分開,則「兩病在踝同向所以分不開」的論述失去其單肌肉層級的支撐。

**P3 — 髖,空對照。** 兩臂的 `HIP_ic` 重疊。

**P4 — 加成性。** `BOTH` 的 `KNEE_ic` 落在 `GASONLY` 與 `SOLONLY` 之間或更極端,**不得**回到
無病灶值附近。`FROZEN_MECHANISM_r410` 觀察到 BOTH ≈ 無病灶(差 0.06°),那是凍結、
0/6 Gate G 的讀數;若在重新最佳化且過 Gate G 的 cell 上**重現**,則該現象是真實的而非跌倒假象,
**並且 P1 的因果讀法失效** —— 此結果須照實回報為 P4 失敗。

**P5 — 存活(來自 r420 偵察,必須在新 cell 上重測)。** 在每一階,`GASONLY` 的 `t_end` 中位數
**低於** `SOLONLY`。此預測若失敗,不影響 P1–P3,但 r420 的偵察觀察即為凍結特有,不可外推。

## 6. 時長控制,事先註冊,非選擇性

對 P1 套用 r417 程序:計算臂內去中心化的 `t_end` → `KNEE_ic` 合併斜率與 Pearson r,
乘以兩臂之間的 `t_end` 差距。**若可歸因於時長的度數超過所報效應的 50%,P1 判為 CONFOUNDED,
不計為成立**,無論是否不重疊。這把尺已經退役過 `FROZEN_MECHANISM_r410`(38%)並保住頭條(9%)。

**此外,`SWINGMATCHED_r419` 的教訓:同時報告站立期與擺盪期時長。**若擺盪期時長隨臂系統性改變,
以共同窗口重測 `KNEE_ic` 並兩者都報。

## 7. 本註冊不能建立什麼

1. 腓腸肌與比目魚肌的差別不只跨越關節:力臂、肌纖維長度、最大等長力、以及最佳化基線增益都不同。
   分開不等於證明是跨越造成的。
2. 串接使每一階依賴前一階,同一 seed 的三階不是獨立樣本。
3. 批次虛無適用:`KNEE_MDC_BATCHNULL_r399.json` 量到同機制家族間 26.7% 的分離率,
   且**沒有任何同機制配對的差距超過 0.5697°**。判讀對照此值,不對照置換底線。
4. 這與病人無關,也與 6.3919° 頭條無關 —— 頭條用的是 KV 0.110 的雙肌肉病灶。
