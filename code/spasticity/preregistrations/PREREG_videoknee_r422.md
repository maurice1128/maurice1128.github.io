# PREREG — 膝@著地在 2D markerless 影片雜訊下的存活 (r422)

**Registered:** 2026-08-26,在對膝終點注入任何雜訊之前。無新模擬,不消耗 Hyfydy 授權。

---

## 1. 為什麼需要這份註冊

頭條是 `knee_angle_l` 於左腳跟著地的邊界差 **6.3919°**,不重疊,置換超出底線 123.2 倍。
`KNEE_MDC_BATCHNULL_r399.json` 同時記載:該值**未達**保守膝 MDC 帶 7.25–7.62°,
而且**文獻上不存在任何神經族群的「膝@著地」MDC**,所有候選門檻都是外推。

`VIDEO_DEGRADATION.json`(242 KB,120 cell,200 重複,含偏航)已做過 2D 影片降級,
**但它的終點是踝關節 ROM,且沿用已退役的 `mdc_deg = 3.8`**。膝終點從未在影片雜訊下測試過。

**臨床上真正要問的不是「3D 標記系統能不能量到 6.39°」,而是「一支矢狀面相機能不能」。**
兩個獨立理由使 MDC 帶不是正確門檻:

1. MDC 是**變化量**門檻(帶 √2),本研究是**單次量測分類**,對應量是單次 SEM 2.62°;
2. 該 SEM 的主導項是**標記重貼**,markerless 無標記可貼,該項不適用。

本註冊不主張這兩點成立,而是**直接量測**:在多大的角度雜訊下,6.3919° 的分離消失。

## 2. 材料

已在磁碟上、已過 Gate G 的頭條兩臂,不新增 cell:

- **SPAS**:`R396SPg110_s{101,102,105,106}`,n=4
- **WEAK**:`R151W_s{101..106}`,n=6

外加穩健性用的完整痙攣階梯 `R393SPg070`、`R393SPg100`、`R396SPg120` 作為次要報告,不影響判定。

## 3. 雜訊模型,在此固定

對每個 cell 的 `knee_angle_l(t)` 逐幀注入:

- **關鍵點抖動** → 角度高斯雜訊,**σ ∈ {0, 1, 2, 3, 4, 5, 6, 8, 10} 度**,獨立同分布逐幀。
- **取樣率** fs ∈ {30, 60} Hz(對原始訊號重新取樣後注入)。
- **相機偏航**(矢狀面外旋轉)→ 角度按 **cos(yaw)** 縮放,yaw ∈ {0, 10, 20, 30} 度固定。
- **事件偵測誤差**:著地時刻位移 **±k 幀**,k ∈ {0, 1, 2},每次重複隨機取號。

每個組合 **n_rep = 200**,固定亂數種子 **20260826**。

**注入後才取讀數**:對每個 cycle 取著地幀的膝角,再對 cycle 取平均 —— 與語料庫慣例一致,
差別僅在讀的是加雜訊後的訊號。

## 4. 判定規則,事先固定

- **主要指標:邊界差**。SPAS 最大值與 WEAK 最小值之差,與無雜訊的 +6.3919° 同義。
- **DISJOINT 保存率** = 200 次重複中兩臂仍不重疊的比例。
- **分類正確率** = 以兩臂中點為閾值的留一分類正確率(10 個 cell)。
- **σ_break** = DISJOINT 保存率首次跌破 **95%** 的最小 σ。
- **σ_chance** = 分類正確率首次跌破 **70%** 的最小 σ。

## 5. 註冊的預測

**P1.** 在 fs = 60、yaw = 0、k = 0 的乾淨條件下,**σ_break ≥ 3.0°**。
**P2.** 在 fs = 30、yaw = 20°、k = 1 的實際手機條件下,**分類正確率在 σ = 2° 時 ≥ 80%**。
**P3.** 偏航的影響小於關鍵點抖動:yaw 由 0 增至 30° 造成的正確率下降,小於 σ 由 0 增至 5° 造成的下降。

**這三個預測都可能失敗,失敗即記為失敗。** 若 σ_break < 2°,結論是**此終點在 2D 影片下不可用**,
必須照實寫入論文,且不得改用較寬鬆的保存率門檻補救。

## 6. 本註冊不能建立什麼

1. 這是**對模擬訊號注入雜訊**,不是真實影片。真實 markerless 誤差不是獨立同分布高斯,
   而是有時間相關性、且在遮蔽與極端姿勢下系統性偏移。本分析**低估**真實誤差。
2. 未建模:受試者間解剖差異、相機高度與鏡頭畸變、步態速度差異、地面反作用力不可得時的
   事件偵測失敗(該項在 `VIDEO_DEGRADATION_A5.json` 對踝終點做過,此處僅以 ±k 幀近似)。
3. 不涉及病人。cell 數僅 10,`KNEE_MDC_BATCHNULL_r399.json` 的同機制家族結構仍適用。
4. 通過本檢定**不代表**臨床可用,只代表「雜訊不是立即的殺手」。

## 7. 禁止事項

不得更改 σ 網格、保存率門檻、正確率門檻或 n_rep。不得在看到結果後新增雜訊條件。
不得改用其他膝終點替代。註冊正文一律不修改,連加註都不行(見 `DEFECT_r417_hash_break.md`)。
若出現 §5 沒有類別的結果,記為 REGISTRATION DESIGN DEFECT,該預測按字面判為失敗。
