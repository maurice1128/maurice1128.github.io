What is here

DirectoryFilesContents
scripts/396 Python analysis scripts. Every statistic in the manuscript and supplement is produced by one of these. Files named fix_rNNN.py are the edits that repaired defects found in adversarial review, kept deliberately as part of the record.
containers/818 JSON result containers. Each holds the numbers one script produced, the inputs it read, and a statement of why it was run.
preregistrations/147 Preregistrations, written before the analysis they govern was run.
hashes/117 SHA-256 sidecars over the preregistrations.
records/3 The defect register, the formally abandoned arms, and the first council audit.

The containers are the reproducible layer. To check a number in the paper, find it in containers/ rather than re-running anything. bindcheck_r572.py is the script that binds three-or-more-decimal values in the text to a container holding that value whose path shares a term with the claim; the manuscript reports its outcome, including the 23 values it could not bind.

What is not here, and why

The raw simulation output is not deposited here

It is roughly 1129 run directories of SCONE output, far past what belongs in a web repository, and it is not redistributed. The manuscript's availability statement commits it to an archival deposit; that deposit is not yet made, and this repository does not stand in for it. Sixteen of those run directories lack a replayed output and contribute to no analysis in the paper.

Nothing here can be re-simulated

The Hyfydy licence under which these simulations were run expired on 27 August 2026. The scripts that read simulation output will not reproduce that output. Analyses that consume the containers need no simulator licence and do run.

Paths are absolute and local

The scripts were written against one machine and read from hard-coded Windows paths. They are published as the record of what was actually run, not as a portable package, and are not expected to execute unchanged elsewhere.
