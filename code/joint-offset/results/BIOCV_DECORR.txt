P1  cos falls as k rises            -> rejection decorrelates the joints
P2  cos(objd) < cos(reproj) at same k -> the arm better in position, worse in angle,
                                       decorrelates more
P3  overlap falls with k, lower for objd -> the joints stop sharing cameras

  k=0: cos(objd)-cos(reproj) = +0.0000   overlap(objd)-overlap(reproj) = +0.0000
  k=1: cos(objd)-cos(reproj) = -0.0126   overlap(objd)-overlap(reproj) = -0.0068
  k=2: cos(objd)-cos(reproj) = -0.0148   overlap(objd)-overlap(reproj) = -0.0275
  k=3: cos(objd)-cos(reproj) = -0.0127   overlap(objd)-overlap(reproj) = -0.0500

READ: if P1-P3 hold, the harm mechanism is established -- per-joint accuracy gains are
bought by decorrelating errors that used to cancel in the angle. If they fail, the
paper must report the harm as unexplained rather than assert a mechanism.
